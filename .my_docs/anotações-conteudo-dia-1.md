CONTEÚDO DA PRIMEIRA AULA:

Preparação do Ambiente: Deixando nossa máquina + ambiente de trabalho da nuvem preparados para o projeto.
Visão geral da AWS: Entendendo como funciona a AWS e como vamos estruturar nossa aplicação para rodar na nuvem.
Criando conta na AWS: Criação de conta para explorar a camada Free da AWS + criação do ambiente de trabalho na nuvem.
Agentes com IA + MCP Server: Você vai entender e aprender como se tornar o profissional de tecnologia moderno que está usando a IA para ser produtivo.
Containerização com Docker usando IA: Como preparar nosso projeto para trabalhar com Docker e como gerar imagens com o uso de IA e MCP Server.
Configurações de segurança na AWS: Preparação da estrutura de comunicação na AWS para receber nosso projeto de forma segura com as melhores práticas.
MCP Server com Postgresql e ECS: Vamos mostrar na prática o uso de MCP Server tanto para conversar com nossos dados quanto para conversar com nosso cluster em tempo real e validar nosso service no ECS.
Validações de segurança com IA: Vamos mostrar como o nosso agente de IA pode ir até nossa conta da AWS e validar se tudo está estruturado de forma segura.
Migrando nossa aplicação para a AWS: Vamos explorar o processo de migração do nosso projeto para rodar na nuvem líder do mercado, realizando a comunicação entre diversos serviços.
Tecnologias que vamos usar nessa fase: ECS, RDS, ECR, Shell Script, IAM.
Primeiro Deploy na AWS: Aprenda a realizar deploy via script para a nuvem + uso de IA para ajudar num script que permita trabalhar com commit hash.
Desafio prático usando ECS + Deploy na nuvem: Após tudo que foi construído na aula, você vai colocar a mão-na-massa do seu lado.
